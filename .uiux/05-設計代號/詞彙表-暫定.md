# 詞彙表（暫定）

2026-11-15。審查紀錄 #9 指出原型裡同一個東西有好幾個名字，這份是 iOS 版先用的版本。多米還沒逐條確認過，所以檔名有「暫定」。「看過官方頁」到「提醒我去訂」那幾列是 0.5 加的（2026-11-25），照程式裡的字寫。

| 用這個 | 不用 | 指什麼 |
|---|---|---|
| 這趟 | 行程（指整趟時） | 一次旅行，例如首爾 5 天 |
| 站 | 行程（指單一個點時）、點、景點 | 排進某個時段的一個地方 |
| 大站／小站 | 大行程／小行程 | 大站要花半天，一天最多 2 個 |
| 時段 | 坑、半天 | 上午、下午、晚上 |
| 留白 | 空坑 | 這個時段故意不排 |
| 在路上 | — | 抵達前、離開後，不能排的時段 |
| 下次再來 | 收藏、種子 | 這趟拿掉或排不進去的站，可以排回來 |
| 去過的 | 籃子（當清單名時） | 拔起來的站 |
| 蘿蔔籃 | 收藏 | 分頁名，裡面是「去過的」和「下次再來」 |
| 順路清單 | 現場再挑的、順路可去 | 自己加的、不排時間、有空再去的地方。每趟一份，可以拿掉（2026-11-25 多米定） |
| 拔起來 | 打卡、完成 | 旅途中去過一站 |
| 那一句 | 心得、筆記 | 去過之後寫的一句話 |
| 要先訂 | 需預約 | 要訂位或買定時票。資料包裡的站看現在的資料 |
| 看過官方頁 | — | 讀過官方頁，後面帶核對那天，例如「看過官方頁 11/25」。票價那一列寫「官方票價」「官方價錢」 |
| 二手資料 | 二手核對 | 旅遊媒體、觀光網站寫的，沒讀到官方頁。後面也帶核對那天 |
| 未核對 | — | 還沒查，或查了沒有結果 |
| 還沒查到 | — | 某一項沒有資料，要自己查，例如「怎麼訂還沒查到」「哪天開賣沒查到」 |
| 這天休館 | — | 那天不開。只有看的地方和藝文說休館，其他寫「這天不開」；改完行程的那句，吃的和咖啡寫「公休」。下一站卡寫「今天休館」 |
| 這個時段不開 | — | 那天有開，排的時段沒開。知道時間就寫「上午：還沒開，16:00 才開」「下午：17:00 就關了」。移到別的時段的格子裡只寫「不開」 |
| 這天要注意 | — | 有開，但那天有事要先知道，例如展望台限制使用。下一站卡寫「今天要注意」 |
| 現在去不了 | — | 歇業、搬走、長期不開 |
| 開放 | — | 一站頁的一組：休館（吃的、咖啡、逛街那些寫公休）、開放時間、最後入場（吃的、咖啡寫最後點餐） |
| 末班／售票／最後時間 | — | 「開放」裡最後時間那一列的小標，講的是末班車船、賣票到幾點，就不寫最後入場 |
| 票價／價錢 | — | 看的、玩的寫票價，吃的和咖啡寫價錢 |
| 怎麼訂 | — | 一站頁的一組：方法、開賣時間、「打開訂票頁」 |
| 訂之前要知道的 | — | 收在「怎麼訂」裡：外國人訂不訂得到、最晚哪天決定、取消規則 |
| 開賣時間 | — | 開始能訂的那一刻。換成台灣時間，後面一定帶（台灣時間） |
| 來源 | — | 看了哪些網頁，點了開瀏覽器 |
| 另一句須知 | — | 資料包原本那句還沒核對的，跟核對過的須知分開放 |
| 提醒我去訂 | — | 檢查這趟裡打開提醒的按鈕，按了才問通知權限 |
| 用講的改行程 | 跟 AI 討論 | 對話改行程 |
| 平常的我 | 設定、偏好 | 「我」分頁裡每趟都沿用的習慣 |
| （估） | — | 距離、時間、花費都是估的時候，數字後面一定帶 |

蘿蔔的比喻只留一個地方：拔起來那一下（2026-11-25 多米定，❓48；原本寫的「每一站旁邊那顆、蘿蔔籃」都不留）。其他介面文字用平常的話。蘿蔔田（整趟總覽圖）2026-11-15 多米看過後拿掉了。

## 產品色

蘿蔔橘，定義在 `mobile/src/theme.ts`，用 `createTheme` 建，畫布用暖色。對比由 `mobile/tests/theme.test.ts` 驗，淺深色全部及格。其餘字級、間距、圓角、元件都是 `@domy/design` 的。

蘿蔔本身的橘、白、葉子綠是角色色，不是介面色，只出現在蘿蔔圖上。

## App icon

`mobile/assets/icon.svg`（多米給的 luoBoTravel.svg）：深綠底、票卡上一根白蘿蔔。2026-11-15 多米決定：icon 用這張，介面維持蘿蔔橘，兩邊顏色不用一致。之後不要再提議把介面改成綠色。
