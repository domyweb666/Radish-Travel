# 詞彙表（暫定）

2026-11-15。審查紀錄 #9 指出原型裡同一個東西有好幾個名字，這份是 iOS 版先用的版本。多米還沒逐條確認過，所以檔名有「暫定」。

| 用這個 | 不用 | 指什麼 |
|---|---|---|
| 這趟 | 行程（指整趟時） | 一次旅行，例如首爾 5 天 |
| 站 | 行程（指單一個點時）、點、景點 | 排進某個時段的一個地方 |
| 大站／小站 | 大行程／小行程 | 大站要花半天，一天最多 2 個 |
| 時段 | 坑、半天 | 上午、下午、晚上 |
| 留白 | 空坑 | 這個時段故意不排 |
| 在路上 | — | 抵達前、離開後，不能排的時段 |
| 下次再來 | 收藏、種子 | 這趟拿掉或排不進去的站，可以排回來 |
| 去過的 | 籃子（當清單名時） | 拔起來的站 |
| 蘿蔔籃 | 收藏 | 分頁名，裡面是「去過的」和「下次再來」 |
| 順路可去 | 現場再挑的 | 不排時間、有空再去的地方 |
| 拔起來 | 打卡、完成 | 旅途中去過一站 |
| 那一句 | 心得、筆記 | 去過之後寫的一句話 |
| 要先訂 | 需預約 | 要訂位或買定時票 |
| 用講的改行程 | 跟 AI 討論 | 對話改行程 |
| 平常的我 | 設定、偏好 | 「我」分頁裡每趟都沿用的習慣 |
| （估） | — | 距離、時間、花費都是估的時候，數字後面一定帶 |

蘿蔔的比喻只留三個地方：蘿蔔田（總覽）、拔起來、蘿蔔籃。其他介面文字用平常的話。

## 產品色

蘿蔔橘，定義在 `mobile/src/theme.ts`，用 `createTheme` 建，畫布用暖色。對比由 `mobile/tests/theme.test.ts` 驗，淺深色全部及格。其餘字級、間距、圓角、元件都是 `@domy/design` 的。

蘿蔔本身的橘、白、葉子綠是角色色，不是介面色，只出現在蘿蔔圖上。
