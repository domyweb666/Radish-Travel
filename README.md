## 看原型

開啟 GitHub Pages 後（Settings → Pages → Deploy from a branch → `main` / root），用手機開 Pages 網址，可以加到主畫面。

原型的限制：

- 行程由本機規則排出來，不是真的 AI。在這裡的「跟 AI 討論」只聽得懂幾種固定說法
- 景點是候選，沒有核對過營業時間、票價、是否還在
- 花費、距離、時間都是粗估
- 資料只存在這支手機的瀏覽器裡，重要的用設定頁的「複製備份」
